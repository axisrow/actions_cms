## Как публикуется статья

1. Черновик кладут в `drafts/<дата>/NN-slug.md` и открывают pull request.
2. Проверка в pull request находит ошибки до публикации: неизвестную рубрику, слишком длинный анонс, сайт, который перестал собираться.
3. Merge — это одобрение. Черновик переезжает в `docs/blog/posts/`, сайт пересобирается и выкладывается на GitHub Pages.

## Из чего состоит черновик

В начале файла — блок с заголовком, датой, рубрикой, анонсом и статусом. Рубрики и их названия на сайте перечислены в `cms.yaml`.

Первый абзац — лид: он виден в списке статей. После него обязательна строка `<!-- more -->`, дальше идёт основной текст.

Адрес статьи берётся из имени файла, поэтому имя пишут латиницей: `01-hello-world.md` превращается в `/blog/<дата>/hello-world/`.

Когда пример станет не нужен, удалите его файл из `docs/blog/posts/` и выполните `cms index sync`.
